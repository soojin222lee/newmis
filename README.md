# PM 대시보드

## 실행 방법

```bash
cd pm-dashboard
node server.js
# → http://localhost:57291
```

## 화면 구성

| 화면 | 설명 |
|------|------|
| 대시보드 | 프로젝트 현황, KPI, 오늘 할 일 |
| 리스크 이력 | 전체 리스크 목록, 필터, 상태 관리 |
| 조치 팝업 | 리스크 상세, 체크리스트, 의견 작성, PM 서명 |

## 주요 기능

- 리스크 버튼 클릭 → 해당 프로젝트 필터링된 이력 화면으로 이동
- 이력 행 클릭 → 조치 작성 팝업
- 체크리스트 + 의견 + 서명 → 확인 완료 저장
- 조치 이력 누적 관리 (data.json에 영속 저장)
- 전체 체크 완료 시 상태 자동 → 조치완료
