# NEW MIS 목업 시스템 사용자 기능 중심 RFP 요청 초안

## 1. 문서 목적

본 문서는 NEW MIS 프로젝트 관리 및 실행예산 목업 시스템을 기준으로, 협력사가 제안 및 견적 산출 시 참고해야 할 사용자 기능 범위를 정리한 RFP 요청 초안이다.

본 문서는 기술 상세 설계서가 아니라, 현업 사용자가 시스템에서 수행해야 하는 업무 기능을 중심으로 작성되었다. 협력사는 본 문서를 기준으로 분석/설계/개발/테스트/마이그레이션/오픈/안정화까지의 수행 범위, 투입 인력, 일정, 산출물, 리스크 관리 방안을 제안해야 한다.

## 2. 구축 대상 시스템 개요

NEW MIS는 프로젝트 생성부터 실행예산 수립, 비용 관리, 외부 시스템 연계, 레포트 조회, 프로젝트 종료까지 지원하는 프로젝트 관리 시스템이다.

주요 사용자는 사업관리자, PM, 팀장(직책자), 관리조직이며, 시스템은 약 3,000명 사용자 규모를 고려한다.

목표 기술 환경은 다음을 기준으로 한다.

- Frontend: Vue
- Backend: Java
- Database: Oracle
- 주요 연계: ERP, 구매시스템, SCM, CRM, HR

## 3. 협력사 제안 범위

협력사는 다음 범위를 포함하여 턴키 또는 준턴키 방식의 수행안을 제시해야 한다.

- 현행 시스템 분석
- 기존 로직 분석 및 승계
- 요구사항 상세화
- 화면/업무 설계
- DB 설계
- 인터페이스 설계
- Frontend 개발
- Backend 개발
- 데이터 마이그레이션
- 단위/통합/사용자 테스트
- 오픈 전환
- 안정화 지원
- 운영 이관

현장대리인 또는 수행 PM은 협력사 개발 인력의 일정, 품질, 이슈, 산출물을 관리해야 한다.

## 4. 사용자 역할별 주요 기능

### 4.1 PM

PM은 본인 담당 프로젝트의 실행예산과 수행비용을 관리한다.

주요 기능은 다음과 같다.

- 내 프로젝트 조회
- 프로젝트 선택 후 상세예산 수립 화면 진입
- 실행예산 버전별 조회
- 작성중 실행예산 수정
- 이전 버전 대비 변경사항 확인
- 결재 요청
- 인건비/외주비/재료비/경비/A/S비 계획 등록 및 수정
- 구매/SCM/ERP 연계 데이터 확인
- 실적 상세 조회
- 프로젝트 종료 정보 확인
- 맞춤 레포트 조회 및 다운로드

### 4.2 팀장

팀장은 팀 내 프로젝트의 주요 이슈와 비용 현황을 확인한다.

주요 기능은 다음과 같다.

- 팀장용 메인 화면 조회
- 팀 내 프로젝트 리스크 요약 확인
- 승인/검수/마감 등 해야 할 일 확인
- AI 챗봇을 통한 프로젝트 현황 질의
- 실행예산 결재 요청 내역 확인

### 4.3 관리자

관리자는 프로젝트 기준정보와 시스템 공통 기준을 관리한다.

주요 기능은 다음과 같다.

- 프로젝트 유형별 정보 관리
- 기준정보 관리
- 사용자 권한 관리
- 레포트 필드 관리
- 인터페이스 기준정보 관리
- 시스템 운영 가이드 관리

## 5. 메인 화면 기능 요건

메인 화면은 사용자 역할에 따라 다르게 보여야 한다.

PM 화면은 본인이 담당하는 프로젝트와 주요 바로가기 중심으로 구성한다.

팀장 화면은 팀 내 프로젝트의 리스크와 해야 할 일을 AI 요약 중심으로 구성한다.

메인 화면 주요 기능은 다음과 같다.

- 역할 전환: PM / 팀장
- 내 프로젝트 목록 조회
- 프로젝트 클릭 시 실행예산 상세 수립 화면 이동
- 일정 확인
- 구매시스템 참고 화면 목록 팝업
- 업무 가이드 챗봇 호출

메인 화면 문구는 다음 기준을 반영한다.

- NEW MIS는.
- 사용은 가볍게, 데이터는 단단하게.
- 편리한 업무 환경과 신뢰할 수 있는 데이터의 연결.

## 6. 프로젝트 정보 관리 기능 요건

프로젝트 정보 메뉴는 다음 하위 메뉴를 포함한다.

- 수주형 프로젝트
- W/G 프로젝트
- 사내 프로젝트
- 투자프로젝트
- 선투입 프로젝트

프로젝트 정보 화면은 목록, 등록, 상세, 변경이력 조회 기능을 제공해야 한다.

수주형 프로젝트는 기본정보와 IF 변경이력을 관리한다. 단계별 기간 정보는 관리하지 않는다.

사내 프로젝트, 투자프로젝트, 선투입 프로젝트는 동일한 화면 구조를 사용하되, 메뉴명과 화면 텍스트를 각 프로젝트 유형에 맞게 표시한다.

## 7. 실행예산 공통 기능 요건

프로젝트 선택 후 바로 상세예산 수립 화면으로 이동해야 한다.

실행예산은 다음 5대 비용 영역으로 관리한다.

- 인건비
- 외주비
- 재료비
- 경비
- A/S비

상단에는 프로젝트 총 실행비용과 각 비용 영역의 금액이 카드 형태로 표시된다.

각 비용 영역 카드를 클릭하면 해당 비용의 월별 예산내역과 상세 등록/수정 화면이 아래에 펼쳐져야 한다.

실행예산은 버전 관리가 가능해야 한다.

- 여러 버전을 탭으로 표시
- 버전 클릭 시 해당 버전의 예산 데이터 조회
- 작성중 버전과 승인완료 버전 구분
- 작성중 버전의 결재 요청
- 이전 버전 대비 변경사항 비교

기준월 이전은 ERP 실적, 기준월 이후는 실행예산 계획을 반영하여 수행비용을 계산한다.

## 8. 인건비 기능 요건

인건비는 다음 상세 계정으로 구분한다.

- 실투입인건비
- 이관인건비
- OT비

### 8.1 실투입인건비

SCM에서 확정완료된 인력만 등록 가능해야 한다.

사용자는 `신규인력투입` 버튼을 클릭하여 투입가능 인력 리스트 팝업을 조회한다.

팝업에는 다음 항목을 표시한다.

- 이름
- P레벨
- 역할
- 투입기간
- 총MM

사용자는 인력을 선택하고 등록한다.

등록 후 월별 MM과 금액은 SCM 확정 데이터를 기준으로 자동 반영한다.

### 8.2 이관인건비

이관인건비는 Receiver Project 기준으로 신규 등록한다.

Sender Project는 타 시스템에서 집행완료 후 조회 전용으로 표시한다.

주요 관리 항목은 다음과 같다.

- Project Type
- 이관예정월
- 금액
- 이관 사유
- 상태

### 8.3 OT비

OT비는 월별 금액을 직접 입력한다.

경비 자원계획과 유사한 월별 그리드에서 계획금액을 입력하고 저장한다.

## 9. 외주비 기능 요건

외주비는 다음 상세 계정으로 구분한다.

- 실투입대상 외주비
- 전문직수수료/제안/기타
- 외주출장비
- 공사MA
- 이관외주비
- 기타외주비

각 계획 리스트에는 순번을 표시한다.

### 9.1 실투입대상 외주비

구매시스템 견적 데이터를 기반으로 계획을 등록한다.

견적 확정 여부를 먼저 선택한다.

- Y: 구매시스템에서 확정 견적 데이터를 불러와 세팅
- N: 사용자가 직접 입력

견적 확정 Y인 경우 구매에서 수신한 외주계약 기본정보는 수정할 수 없어야 한다.

월별 검수계획금액 확정 팝업을 제공한다.

팝업에서는 견적 기준 월별 금액을 조회하고, 실투입 전표가 없는 월에 한해 금액을 보정할 수 있어야 한다.

### 9.2 전문직수수료/제안/기타

실투입대상 외주비와 유사한 구조로 신규 계획을 등록한다.

단, 전문직수수료는 실투입 생성 대상이 아니다.

월별 검수계획금액 확정 시 전체 금액을 기간 내 월별로 배분하고, 사용자가 확정금액을 직접 보정할 수 있어야 한다.

### 9.3 외주출장비

기등록 계획 리스트를 먼저 표시한다.

신규 등록 시 프로젝트에 매핑된 계약번호 또는 PO를 검색할 수 있어야 한다.

등록 항목은 출장내역, 집행예정월, 출장금액, 항공료, 숙박비, 교통비, 일비, 기타비용 등이다.

### 9.4 공사MA

구매시스템의 물품정보를 기반으로 계획을 수립한다.

유지보수 시작일, 종료일, 검수유형, 공급단가, 검수집행월, 검수여부를 관리한다.

검수집행월은 기본적으로 유지보수 종료월로 세팅되며, 검수 이력이 없는 경우에만 수정 가능하다.

### 9.5 이관외주비

Receiver Project만 신규 등록 가능하다.

Sender Project는 집행완료 후 조회 전용으로 표시한다.

### 9.6 기타외주비

집행월, 금액, 설명을 입력하여 단순 계획을 등록한다.

## 10. 재료비 기능 요건

재료비는 다음 상세 계정으로 구분한다.

- 상품재료비
- 감가상각비
- 이관재료비

### 10.1 상품재료비

구매시스템 견적 데이터를 기반으로 계획을 등록한다.

기등록 상품계획은 PO 기준 1줄로 표시한다.

라인 클릭 시 항번별 상세 내역을 표시한다.

신규 등록 시 견적선정유무를 선택한다.

- Y: 구매 견적 데이터 조회 후 등록
- N: 직접 입력

검수 계획 등록 팝업을 통해 수량 기준 검수 예정월을 등록한다.

### 10.2 감가상각비

기등록 감가상각 계획 리스트를 먼저 표시한다.

신규 등록 시 감가상각 계정, 감가상각 개월수, 감가상각 시작일을 입력한다.

월별 금액은 자동 배분하되, 필요 시 팝업에서 월별 금액을 보정할 수 있어야 한다.

### 10.3 이관재료비

이관외주비와 동일한 방식으로 관리한다.

Receiver Project만 신규 등록 가능하고, Sender Project는 조회 전용이다.

## 11. 경비 기능 요건

경비는 별도의 요약 화면과 입력 화면을 나누지 않고, 월별 자원계획 그리드에서 직접 작성한다.

경비는 중계정 기준 통제/비통제로 구분한다.

소계정별 월별 계획금액을 입력한다.

통제 중계정은 ERP 가용예산을 초과할 수 없다.

가용예산 조회 팝업을 제공해야 한다.

## 12. A/S비 기능 요건

A/S비는 A/S 프로젝트에 수립할 비용 계정이다.

다음 항목을 직접 입력한다.

- 인건비
- 외주비
- 재료비
- 경비

입력 후 A/S비 총액에 반영한다.

## 13. 실적 조회 기능 요건

월별 예산내역에서 과거월 금액은 파란색 링크와 밑줄로 표시한다.

사용자가 과거월 금액을 클릭하면 실적 상세 팝업을 표시한다.

실적 상세 팝업은 비용 영역별로 다르게 구성한다.

- 인건비 실적조회
- 외주비 실적조회
- 재료비 실적조회
- 경비 실적조회

미래월 계획금액 클릭 시에는 해당 월의 계획 상세를 조회할 수 있어야 한다.

## 14. 구매시스템 참고 기능 요건

메인 화면에 `구매시스템 참고` 버튼을 제공한다.

버튼은 빨간색 글씨와 빨간색 테두리로 표시한다.

버튼 클릭 시 구매시스템 참고 화면 목록이 표시된다.

현재 표시 대상은 다음 5개이다.

- 01 외주실투입구매요청
- 02 상품재료비 구매요청
- 03 공사MA 구매요청
- 04 외주출장비 요청상세
- 05 검수상세 > 검수계획

각 참고 화면은 실제 구매시스템 원본 화면을 참고하기 위한 목업이며, NEW MIS와 매핑되는 필드를 빨간색 박스로 표시한다.

## 15. 레포트 기능 요건

레포트 메뉴를 제공한다.

사용자는 레포트 유형을 선택하고 필요한 필드를 직접 선택할 수 있어야 한다.

프로젝트번호는 키값이므로 기본 선택 상태이며 해제할 수 없다.

필드 선택 순서가 조회 결과 컬럼 순서가 되어야 한다.

기본값은 모든 필드 선택 상태이다.

조회 결과는 사용자가 선택한 필드만 표시한다.

엑셀 다운로드 시 화면 컬럼 순서를 유지한다.

## 16. 프로젝트 종료 기능 요건

프로젝트 종료 메뉴를 제공한다.

프로젝트 리스트에서 종료 대상 프로젝트를 선택하면 종료 상세 화면으로 이동한다.

종료 상세 화면에서는 다음 정보를 확인한다.

- 구매 검수 완료 여부
- 산출물 등록 여부
- 빌링 여부
- 계획 종료일
- 프로젝트 종료일
- 종료 선언일
- 사후점검 결과보고 계획

## 17. 화면 업무 가이드 챗봇 요건

각 화면에는 업무 가이드 챗봇 아이콘을 제공한다.

챗봇은 현재 사용자가 보고 있는 화면을 기준으로 답변한다.

답변 범위는 다음 정보를 기준으로 제한한다.

- active screen id
- active nav id
- 화면별 프론트 파일
- 화면 주석
- 업무 로직 메타데이터

사용자는 해당 화면의 기능, 소스 위치, 백엔드 후보, 업무 규칙을 질문할 수 있어야 한다.

## 18. 외부 시스템 연계 기능 요건

### 18.1 SCM

SCM은 확정완료된 인력 정보를 제공한다.

NEW MIS는 해당 인력을 조회하고 인건비 계획에 등록한다.

### 18.2 구매시스템

구매시스템은 견적, 계약, PO, 출장비, 검수계획, 물품정보 데이터를 제공한다.

NEW MIS는 구매시스템 데이터를 실행예산 계획과 매핑한다.

### 18.3 ERP

ERP는 실적 원가와 가용예산 정보를 제공한다.

기준월 이전 실적 반영, 경비 통제 계정 가용예산 확인, 실행예산 확정 후 ERP 전송 기능을 고려해야 한다.
