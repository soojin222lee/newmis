# 메인 홈 — Agent와의 업무 대화 (시안 · feature/nj 전용)

> 근거 데이터: [`docs/rawdata/screens/main-home-agent.yaml`](rawdata/screens/main-home-agent.yaml) · 코드: `public/js/home-agent.js`
> develop 의 메인 홈(`01-메인홈-MyWork.md` · `main-home-v2.yaml`)은 그대로이며, 이 문서는 feature/nj 시안 기준입니다.

## 1. 컨셉

홈을 **Agent와 나누는 업무 대화** 한 화면으로 바꿉니다. 사용자는 40~50대 PM이라, 메뉴를 찾아다니기보다
"오늘 뭘 봐야 하는지"를 Agent가 먼저 말해 주고, PM은 버튼을 누르거나 편하게 글로 이어 묻는 흐름입니다.

- **매일 아침 브리핑**: 해야 할 일 · 이상징후 · 결재 진행 건수와, 먼저 볼 3가지(조정안이 준비된 건 · 편성 초안 · 집행 속도)
- **이어서 묻기**: 브리핑 아래 추천 질문 버튼 → 조정안 카드(표 + 이유 + [이대로 반영] · [금액 바꿔서 반영])
- **주제마다 대화 따로**: 프로젝트 A를 묻다 B로 넘어가도 답이 섞이지 않게, 오른쪽 **대화 기록**에서 새 대화를 열고 지난 대화를 다시 엽니다.

## 2. 화면 구성

| 영역 | 내용 |
|---|---|
| 왼쪽 레일 | 원래 레일 모양(회색 머리글 + 흰 카드) 그대로 **즐겨찾기**(편집 → 즐겨찾기 패널) → **최근 본 화면**(자동 기록, 시각 표시) → **담당 프로젝트**(원래 행 · 펼침 그대로, 먼저 5개 + [나머지 N개 보기]로 전체 · 이름 검색, 펼치기 칸 · 줄 높이만 작게). 아래 업무 프로세스 · 구매시스템 참고는 잠깐 숨김 |
| 가운데 | 머리(대화 제목 · 날짜 · 실적 반영 기준) → 대화 → 입력창 [보내기] |
| 오른쪽 | **대화 기록** — [+ 새 대화] · 검색 · 오늘 / 어제 / 지난주 묶음 · ◧ 아이콘으로 접기(접으면 대화 머리 오른쪽 [◧ 대화 기록] 버튼으로 다시 펴기) |

- 질문을 보내면 브리핑은 "▲ 오늘 08:30 Agent 브리핑 (3가지) 다시 보기" 한 줄로 접힙니다.
- [+ 새 대화]는 "이런 일을 도와드려요" 4칸(할 일 정리 · 숫자 원인 분석 · 이상징후 확인 · 화면 찾기)으로 시작합니다.
- 홈에서는 [AI에게 물어보기] 버튼과 AI 창을 숨깁니다(홈 자체가 대화 화면이라 겹치지 않게).

## 3. 다른 화면(원가조정 등)에서의 대화 기록

- [✦ AI에게 물어보기]로 연 **AI 창 머리의 문서 아이콘**([⧉ 새 창으로 띄우기] 왼쪽) → 대화 기록 드롭다운(오늘 · 어제 · 지난주).
- 기록을 고르면 **AI 창 안에** 그 대화가 펼쳐지고, 아래 입력창("이 대화에 이어서 물어보세요")으로 **화면을 떠나지 않고 그 대화에 이어 묻습니다.**
  이어 물은 내용은 같은 대화 기록에 남아 홈에서 열어도 이어져 있습니다. [← 지금 대화로]로 원가조정 Agent 대화로 돌아갑니다.
- 홈으로 보내는 "홈에서 이어가기"는 두지 않습니다 — 원가조정을 보다가 연 대화는 그 화면을 보면서 이어 가는 게 자연스럽기 때문입니다.

## 4. 목업 범위

- Agent 답은 목업입니다. 정해진 질문(조정안 · 외주비 원인 · 이상징후 · 결재 위치 · 할 일 · 재료비 남은 계획)은 카드로,
  그 밖의 글은 "정해진 질문에만 답할 수 있어요" 안내와 예시 버튼으로 답합니다.
- [이대로 반영]은 반영 완료 표시와 안내만 하고 실제 예산은 바꾸지 않습니다.
- 대화 기록 · 최근 본 화면 · 대화 기록 접힘 상태는 이 브라우저에만 저장됩니다(localStorage).
