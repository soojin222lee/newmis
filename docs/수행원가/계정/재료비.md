## 1. 개요

- **위치**: 수행원가(원가관리) > 원가조정 > 5대 비용계정 중 **재료비**(`CATS[2]`, `budget-status.js:742` = `['인건비','외주비','재료비','경비','A/S Cost']`).
- **역할**: 프로젝트 실행예산 중 재료비 계정을, **3개 상세구분(상품재료비 / 감가상각비 / 이관재료비)** 으로 나누어 월별 계획을 수립·수정하는 편집기.
- **핵심 특징**:
  - 상품재료비는 **구매시스템 견적(그룹)** 을 불러와 견적 1건 단위로 계획을 등록하며, 견적 물품정보는 수정하지 않고 **검수 계획(수량 기준 검수 예정월)** 만 별도 팝업에서 등록한다.
  - 감가상각비는 **감가상각 4개 계정** 중 선택 + 시작월/개월수/총액 → **월별 상각액 자동배분**(수기 보정 가능).
  - 이관재료비는 **Receiver Project(수취)** 만 신규 등록 가능(플러스 금액), Sender Project/집행완료 건은 조회 전용.
  - 3개 상세구분의 값이 재료비 계정의 **월별 예산내역 테이블**에 합산 반영된다(`getMonthlyBudgetRows`, `budget-status-4.js:1243`).

## 3. 상세구분 (3종)

`materialKind` 전역 상태(기본값 `'item'`, `budget-status-2.js:2853`)로 서브탭을 구분한다. 전환은 `switchMaterialKind(kind)` (`budget-status-2.js:3045`) — `materialKind` 변경 + 편집중 ID 초기화(`editingMaterialItemId`, `editingOtherMaterialId`) + 재렌더.

탭 렌더 `renderMaterialKindTabs` (`budget-status-4.js:1275`, 활성):

| step | `materialKind` | 라벨 | 설명 |
|---|---|---|---|
| 01 | `item` | 상품재료비 | 견적등록/납기 |
| 02 | `depreciation` | 감가상각비 | 자산/라이선스 월상각 |
| 03 | `other` | 이관재료비 | 이관월/금액/사유 |

### 3-1. 상품재료비 (`item`)
- **의미**: 구매시스템에서 수신된 **견적(구매건/PO 단위 그룹)** 기반의 실물/SW 재료비. 견적이 아직 없으면 직접입력으로 기간·금액을 배분.
- **계획 수립 방식**: 견적선정유무(Y/N) 선택 →
  - **Y(견적 사용)**: 견적 그룹 1건 선택 → 물품정보(구매건명/업체/품목)는 읽기전용 → **검수 계획 팝업**에서 물품 수량만큼 생성된 행의 **검수 예정월**을 조정·저장 → 검수월별 금액이 월별 계획으로 배분.
  - **N(직접 입력)**: 품목정보 직접 입력 + 예산 시작월~종료월 + 예산금액 → **균등 배분**(`buildMaterialAllocations`).

### 3-2. 감가상각비 (`depreciation`)
- **의미**: 개발서버 장비, 프로젝트 전용 라이선스 등 **자산/라이선스의 월 감가상각액**.
- **계획 수립 방식**: 감가상각 계정(4종) 선택 → 시작월 / 개월수 / 상각총액 입력 → `buildDepreciationMonthlyRowsFinal`로 **월별 상각액 자동 균등배분**(마지막 월에 잔액 보정) → 필요 시 "월별 금액 보정" 팝업으로 수기 조정 → 저장.

### 3-3. 이관재료비 (`other`, 내부 상태명 `other` / UI명 "이관재료비")
- **의미**: 타 프로젝트로부터의 **재료비 이관(수취/배부)**. 임시 라이선스·소모품 등 견적과 별도로 잡는 비용도 포함(레거시 설명 잔존).
- **계획 수립 방식**: **Receiver Project(수취)** 기준 신규 등록만 가능하며 금액은 **절대값(플러스)** 로 저장. Sender Project(배부, 마이너스 금액) 및 집행완료 건은 타 시스템에서 수신되어 **조회 전용**.

- **검수 계획 팝업**: `renderMaterialInspectionPlanPopupFinal` (`budget-status-5.js:769`).
- 초기 진입 시 `ensureMaterialItemMockRowsFinal()` (`budget-status.js:3146`)로 목업 상품계획 2건 주입(`mi-mock-quote-001` 등).

## 5. 비즈니스 로직 & 규칙

### 5-1. 견적 연동 (상품재료비)
- **견적 데이터 소스**: `materialPurchaseQuoteGroupsFinal` (`budget-status.js:3053`) — 구매건 단위 그룹 배열(quoteNo, purchaseName, vendor, receivedAt, poNo, inspectionDueMonth, lines[]). 목업 3건(HRMS 구매 / 개발·검수 도구 / 보안 패키지).
- **로드/조회**: "견적 실시간 조회" 버튼은 목업이라 `showToast('구매시스템 상품재료비 견적 데이터를 새로 조회했습니다.')`만 호출(`budget-status-4.js:884`). 실제 조회 API 없음 → **SRS에서 구매시스템 연동 인터페이스로 승격 대상**.
- **견적 선택**: `selectMaterialQuoteLine(quoteNo)` (`budget-status-5.js:622`) → `materialSelectedQuoteNoFinal` 설정, `materialItemEditorModeFinal='new'`, Y 모드.
- **견적 금액**: `materialQuoteAmountFinal(group)` (`budget-status.js:3099`) = 그룹 lines의 amount 합.
- **물품정보 불변**: Y 모드에서 구매건명/업체/품목/수량/단위/견적금액 input은 `readonly`. 규칙 명시(`budget-status-5.js:862`): "구매시스템 물품정보는 수정하지 않고, 실행예산에서는 검수 계획만 별도 팝업에서 등록합니다."

### 5-2. 검수 계획 (상품재료비 Y 모드)
- `buildMaterialInspectionRowsFinal(lines, baseMonth)` (`budget-status-5.js:701`): 각 라인의 **수량(quantity)만큼 행 생성**, 라인 금액을 수량으로 균등 분할(마지막 순번에 잔액 보정), 각 행의 검수월은 baseMonth부터 순차 증가.
- 팝업 저장 `saveMaterialInspectionPlanFinal` (`budget-status-5.js:752`): 모든 행의 검수월 필수 → `materialInspectionPlanRowsFinal`에 반영, hidden `material-inspection-due`에 최소 검수월 세팅.
- 저장 시(`saveMaterialItem`) 검수월별 금액을 합산하여 `monthlyAllocations` 생성(월 그룹핑, `budget-status-5.js:897-903`).

### 5-3. 실적 발생 시 수정 불가 (상품재료비)
- `editMaterialItem(id)` (`budget-status-5.js:651`): `row.actualized === true`이면 `showToast('이미 실적이 발생한 상품재료비는 수정할 수 없습니다.')` 후 중단.
- 목록에서도 `row.actualized`면 수정 버튼 `disabled`("수정불가") 표시(`budget-status-5.js:990`).
- → **규칙: 실적(actualized) 미발생 = 계획 상태의 건만 수정 가능.**

### 5-4. 직접입력 배분 (상품재료비 N 모드)
- `buildMaterialAllocations(startMonth, endMonth, amount)` (`budget-status.js:1666`): `monthRange`로 월 목록 산출 → `floor(amount/월수)` 균등 배분, 마지막 월에 나머지(remainder) 가산.

### 5-5. 감가상각 배분
- `buildDepreciationMonthlyRowsFinal(startMonth, monthCount, totalAmount)` (`budget-status-5.js:125`): 개월수만큼 `floor(total/count)` 균등, 마지막 월 잔액 보정.
- `getDepPlanMonthlyRowsFinal(plan)` (`budget-status-5.js:137`): 저장된 `monthlyAllocations` 우선, 없으면 start/months/totalAmount(또는 `monthly*months`)로 재계산.
- "월별 금액 보정"으로 수기 조정 후 저장 가능(`saveDepreciationAdjustPopupFinal`, `budget-status-5.js:208`).

### 5-6. 이관재료비 규칙
- **신규는 Receiver만**: `saveOtherMaterialExpense` (`budget-status-5.js:494`)는 항상 `transferType:'Receiver Project'`, `amount: Math.abs(amount)`(플러스)로 저장.
- **조회 전용 잠금**: `editOtherMaterialExpense` (`budget-status-5.js:408`) 및 저장부에서 `transferType === 'Sender Project' || actualized || status === '집행완료'`이면 수정 차단(toast: 'Sender Project 또는 집행완료 건은 조회만/수정할 수 없습니다').

### 5-7. 검증 흐름 (저장 시)
- **상품재료비** `saveMaterialItem` (`budget-status-5.js:867`):

### 5-8. 월별 예산내역 반영 (계정 통합)
- `getAccountDetailRows(CATS[2])` (`budget-status-4.js:1217`) = `[상품재료비, 감가상각비, 이관재료비]`(ratio 없음).
- `getMonthlyBudgetRows(data, account)` (`budget-status-4.js:1243`)에서 재료비(CATS[2])는 상세행별로 아래처럼 월값 산출(`budget-status-4.js:1255-1272`):
  - `감가상각비` 월값 = `getDepreciationAmountForMonth(month)` (`budget-status-5.js:146`, 감가상각 계획 월배분 합).
  - `이관재료비` 월값 = `getMaterialTransferAmountForMonthFinal(month)` (`budget-status-4.js:1205`, 해당 월 이관금액 합).
  - `상품재료비` 월값 = `max(base − depreciation − transfer, 0)` (base=`getMonthAccountValue(mo, account)`, 기존 계정 월계획).
  - 실적: 이관재료비=`getMaterialTransferActualTotalFinal()`(actualized 합), 감가상각비=0, 상품재료비=`max(totalActual − 이관실적, 0)`.

> **주의(설계상 특이점)**: 상품재료비 상세 계획(`budgetMaterialItems`)의 `monthlyAllocations`는 월별 예산내역 테이블에 **직접 합산되지 않는다**. 테이블의 상품재료비 값은 기존 계정 월계획(`base`)에서 감가상각·이관액을 차감하는 방식이다. 즉 상품재료비 등록 화면은 **계획 상세 관리(견적/검수/품목)** 계층이고, 감가상각·이관만 계정 월예산에 동적으로 주입된다. → SRS에서 "상품재료비 상세 → 계정 월예산 반영" 여부를 명확히 정의 필요.

## 9. 사용자 플로우

### 9-1. 상품재료비(견적 Y)

2. "신규 등록" → 견적선정유무 **Y** → 견적 그룹 1건 클릭(`selectMaterialQuoteLine`).

## 11. 요구사항 후보 (bullet)

- **[진입]** 재료비 계정은 `#/budget-adjust/material?pj=<프로젝트>` 딥링크로 직접 진입 가능해야 한다.
- **[서브탭]** 재료비는 상품재료비/감가상각비/이관재료비 3개 상세구분 탭을 제공하고, 탭 전환 시 편집 상태를 초기화해야 한다.
- **[상품-견적연동]** 상품재료비는 구매시스템 견적(구매건/PO 그룹)을 조회·선택하여 등록하며, 선택된 견적의 물품정보는 편집할 수 없어야 한다(읽기전용).
- **[상품-검수계획]** 견적 사용 시 물품 수량만큼 검수 예정월 행을 생성하고, 사용자가 조정한 검수월별 금액을 월별 계획으로 배분해야 한다.
- **[상품-직접입력]** 견적 미확정 시 예산 시작월~종료월과 금액으로 월별 균등 배분(잔액 마지막 월)해야 한다.
- **[상품-수정제약]** 실적이 발생한(actualized) 상품재료비 계획은 수정할 수 없어야 하며, UI에서 수정 버튼을 비활성('수정불가')해야 한다.
- **[상품-검증]** 저장 시 견적 선택/금액/검수월(또는 직접입력 기간)/품목 필수값을 검증해야 한다.
- **[감가상각-계정]** 감가상각비는 4개 감가상각 계정(713801/713802/713803/713806) 중 선택하도록 한다.
- **[감가상각-배분]** 시작월/개월수/상각총액으로 월별 상각액을 자동 균등배분(잔액 보정)하고, 수기 보정 팝업을 제공해야 한다.
- **[감가상각-반영]** 감가상각 월배분액은 재료비 계정 월별 예산내역의 '감가상각비' 행으로 반영되어야 한다.
- **[이관-방향]** 이관재료비 신규 등록은 Receiver Project(수취, 플러스 금액)만 허용하고, Sender Project/집행완료 건은 조회 전용이어야 한다.
- **[이관-반영]** 이관금액은 월별 예산내역의 '이관재료비' 행(및 실적)으로 반영되어야 한다.
- **[월예산 통합]** 재료비 계정 월예산은 상품재료비/감가상각비/이관재료비 3행으로 분해되며, 상품재료비 = 계정 월계획 − 감가상각 − 이관(음수 방지)으로 산출한다. *(상품재료비 상세 계획의 월예산 직접 반영 여부는 정책 확정 필요.)*
- **[연동-승격]** 목업으로 처리된 견적/검수 실적/감가상각 원장/이관 인터페이스는 실제 외부 시스템 연동으로 정의해야 한다.
