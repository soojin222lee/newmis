# 수행원가 > 원가현황 (status)
> SRS Agent 입력용. 코드 근거(파일:라인) 기반. 경로 접두는 `C:\Workspace\budget\public\js\`, 이하 파일명만 표기.
> ⚠️ 렌더러는 `budget-status.js`+`budget-status-2~5.js` 5분할이며 동일 함수를 여러 번 override 한다("뒤에 정의된 코드가 앞을 override"). 본 문서는 최종 유효 버전 기준.

## 1. 개요
- **정의**: 수행원가 3개 소메뉴 중 하나. 진입 모드 `costMode='status'`로 프로젝트 실행예산의 **집행 현황을 조회(읽기 위주)** 하는 화면. 목록 → 프로젝트 상세 → 전체 현황(월별 계획/실적 그리드)을 본다.
- **공유 화면**: 3개 소메뉴는 모두 한 화면(`s-budget`)과 같은 렌더러(`renderBudgetPage`)를 공유하고, `costMode`(`budget-status-5.js:69`, 기본 `'history'`)와 `budgetDetailStep`/`budgetSetupStage`로 진입 지점만 달라진다.
- **원가현황 고유 진입 지점**: `openBudgetProjectScreen` 종료 직후 `costMode==='status'`이면 `showBudgetSummaryGrid()`가 호출되어 **전체 현황(월별 계획/실적 요약 그리드)** 으로 바로 진입한다(`budget-status-5.js:92`).
- **핵심 컨셉**: 기준월(당월 = `isPastActualMonth` 경계, 목업상 `'2026-07'`) **이전은 ERP 실적(actual)**, **이후는 실행예산 계획(plan)/투입확정(quasi)** 을 반영해 수행비용을 계산한다(`budget-status.js:13`, `catVal` `budget-status.js:797`).
- **비용 계정 5종**(`CATS`): 인건비·외주비·재료비·경비·A/S Cost. 이관/집행 요약 테이블은 앞 4계정(`BUDGET_ACCT_LABELS`, `budget-status.js:1243`)을 사용.

## 2. 진입 경로 & URL (딥링크)
| 항목 | 값 |
|---|---|
| costMode | `'status'` |
| 목록 진입 | `showCostStatus()` → `costMode='status'; showBudget()` (`budget-cost-status.js:8`) |
| 프로젝트 진입 | `openCostStatus(k)` → `costMode='status'; openBudgetProjectScreen(k||'budgetMock')` (`budget-cost-status.js:10`) |
| 라우트 | `#/budget-status` (`ROUTE_ACTIONS['budget-status']`, `budget-cost-status.js:14`) |
| 딥링크 | `#/budget-status?pj=<프로젝트키>` |

- **URL → 화면**: 라우트 액션이 `routeQueryParam('pj')`(`app.js:119` 계열)로 프로젝트 키를 읽어, 있으면 `costMode='status'` 후 `openBudgetProjectScreen(pj)`로 그 프로젝트 상세 바로 진입, 없으면 `showCostStatus()`로 목록(`budget-cost-status.js:15~17`).
- **화면 → URL**: `SCREEN_ROUTES['s-budget']`(`app.js:49~62`)가 현재 상태로 해시 역산. `costMode==='status'`이면 base=`budget-status`, 상세 뷰(`budgetScreenView==='detail'`)면 끝에 `?pj=<currentBudgetProj>` 부착. `updateHashForScreen('s-budget')`(`app.js:112`)가 반영(`_suppressNextHash`로 재진입 방지).
- **양방향 일치**: URL이 화면을, 화면 상태가 URL을 서로 갱신 → 새로고침/공유 링크로 동일 화면 복원.

## 3. 화면 구성
1. **프로젝트 목록**(`budgetScreenView==='list'`, `renderBudgetListView`): `EXEC_BUDGET_PROJECTS`(`budget-status.js:1200~1217`, 16건) 카드/행. 검색·유형·상태·고객·수행조직·PM 필터(`budgetSearchQuery` 등, `budget-status-3.js:1796~1809`). 유형/상태 뱃지 클래스는 `execTypeClass`/`execStatusClass`(`budget-status.js:1229/1237`).
2. **총액 KPI 바**(`renderTotalBudgetBar`, `budget-status-3.js:2018`): 프로젝트명·단계 뱃지·`D+n일`, 4개 KPI 카드 — **계획예산**(총액), **실집행**(집행률 `actual/budget`), **투입확정**(확정률 `quasi/budget`), **투입미정**(잔여율 `remain/budget`). 각 카드에 진행바+% 표시.
3. **전체 현황 그리드**(`showBudgetSummaryGrid` → `renderProjectPlanSummary`, `budget-status-2.js:2292 / 2597`):
   - 상단 요약: 총 계획예산 / 실행예산 진행률(바) / 실적 / 잔여예산.
   - 표: 계정 계층(총실행비용 → 5계정 → 소계정), **종합 4열(계획·실적·잔여예산·진행률)** + **월별 2열(계획·실적)** 반복(`monthHeaders`/`monthSubHeaders`, `budget-status-2.js:2600~2601`).
   - 소계정 정의 `getProjectSummaryGridRows`(`budget-status-2.js:2575`): 인건비(실투입/이관/증업OT), 외주비(실투입/공사·MA/기타), 재료비(재료비/감가상각비), 경비(A/S Cost).
4. **실적 상세 모달**(3.4절): 과거월 실적 금액 클릭 시 팝업.
5. 하단 이동 버튼: `예산 확정 화면 →`(`budgetDetailStep='confirm'`)로 확정 단계 이동 가능.

## 4. 비즈니스 로직 & 규칙
- **당월 경계**: `isPastActualMonth(month)`는 `month < '2026-07'`(`budget-status-4.js:68`). 경계 이전 월 = 실적(actual) 셀, 이후 월 = 계획(plan)/확정(quasi) 셀.
- **집행 합계 산식**(`budget-status.js:801~805`):
  - `calcActual` = Σ actual(a), `calcQuasi` = Σ quasi(q), `calcRemain` = plan − actual − quasi.
  - `catVal`(`797`): actual월은 `{a,q}` 사용, plan월은 `{q,p}` 사용.
- **KPI 비율**(`renderTotalBudgetBar` `2019~2021`): 집행률·확정률·잔여율 = 각 값 / 총액, 진행바 폭은 max 100%로 클램프.
- **실적 클릭 규칙**: `summaryActualCell`(`budget-status-2.js:2590`)은 `row.account && isPastActualMonth(month) && actual>0`일 때만 클릭 버튼(`showActualDetailModal`) 생성. 인건비 계획월 금액은 별도 `showLaborPlanDetailModal`(투입계획 조회)로 연결(`actualCellHtml` `budget-status-4.js:72~80`).
- **읽기 전용 성격**: 원가현황은 이관/편집 UI를 노출하지 않고 조회·드릴다운 위주(편집은 원가조정 소메뉴 담당).

## 5. 프론트엔드 로직 (파일:함수 인용)
- 진입/라우트: `showCostStatus` / `openCostStatus` / `ROUTE_ACTIONS['budget-status']` (`budget-cost-status.js:8,10,14`).
- 공통 진입: `openBudgetProjectScreen`(`budget-status-5.js:71` override) → `budgetScreenView='detail'`, `budgetDetailStep='setup'` 세팅 후 `renderBudgetPage()` → `costMode==='status'`이면 `showBudgetSummaryGrid()`(`:92`).
- 렌더 코어: `renderBudgetPage`(최종 유효본 `budget-status-3.js:3296`) — list면 `renderBudgetListView`, 아니면 총액바 + step 분기.
- 전체 현황: `showBudgetSummaryGrid`(`budget-status-2.js:2292`) → `renderProjectPlanSummary`(`:2597`) → 행 데이터 `getProjectSummaryGridRows`/`makeSummaryRow`(`:2575`).
- 실적 드릴다운: `summaryActualCell`(`:2590`) → `showActualDetailModal(account,month,detailName)`(`budget-status-4.js:180`), 인건비 계획 `showLaborPlanDetailModal`(`budget-status-2.js:2691`).
- KPI 바: `renderTotalBudgetBar`(`budget-status-3.js:2018`).

## 6. 데이터 모델
- **`BUDGET_SOURCE[projKey]`**(`budget-status.js:141~`): `{ projName, stage, dplus, start, end, current, plan{계정:금액}, transfer{계정:±금액}, months[] }`.
- **`months[]` 항목**: `{ m:'YYYY-MM', type:'actual'|'plan', 인건비:{a|p,q,details[]}, 외주비:{...}, 재료비:{...}, 경비:{...}, 'A/S Cost':{...} }`. actual월은 `a`(실적), plan월은 `p`(계획)+`q`(투입확정) 보유.
- **details 스키마**: 계정별 `DETAIL_SCHEMA`(`budget-status.js:26~82`) — 인건비(이름/조직/역할/MM/단가/금액), 외주비·재료비·A/S(업체·품목/실적금액/PO금액), 경비(항목/금액). PO 계약금액은 `PO_AMOUNTS`(`:85~131`)로 조회.
- **프로젝트 목록**: `EXEC_BUDGET_PROJECTS`(`budget-status.js:1200`) — `{key,no,name,type,status,pm,salesOrg,customer,period}`.
- **소계정 비율(목업)**: `getProjectSummaryGridRows`의 children 비율(`budget-status-2.js:2578~2581`), 재료비 감가상각비는 `getDepreciationAmountForMonth`로 월별 산출.

## 7. 사용자 플로우
1. 상단 메뉴 "원가현황" 클릭 → `#/budget-status` → 프로젝트 목록.
2. (또는) 홈 Work Feed에서 `openCostStatus(k)` / 딥링크 `?pj=k`로 특정 프로젝트 바로 진입.
3. 프로젝트 선택 → `openBudgetProjectScreen(k)` → 총액 KPI 바 + **전체 현황 그리드**(월별 계획/실적) 표시.
4. 종합/월별 KPI로 집행률·잔여 확인 → 과거월 **실적 금액(파란 링크) 클릭** → `실적조회` 모달에서 계정별 상세 실적(탭·엑셀·합계) 확인.
5. 필요 시 `예산 확정 화면 →`으로 확정 단계 이동, 또는 `← 목록으로` 복귀.

## 9. 요구사항 후보
- 사용자는 실행예산 프로젝트 목록을 검색·필터(유형/상태/고객/수행조직/PM)로 조회할 수 있어야 한다.
- 원가현황은 `#/budget-status?pj=<key>` 딥링크로 특정 프로젝트에 바로 진입할 수 있어야 하고, 화면 상태 변화가 URL에 반영되어야 한다.
- 프로젝트 상세는 총액 대비 실집행/투입확정/투입미정을 KPI(금액+비율+진행바)로 제시해야 한다.
- 수행비용은 기준월 이전은 ERP 실적, 이후는 실행예산 계획/투입확정으로 산정해 월별 계획·실적을 병렬 표시해야 한다.
- 계정은 총실행비용 → 5대 계정 → 소계정 계층으로 집계·표시해야 한다.
- 과거월 실적 금액은 클릭 시 계정별 상세 실적 내역(항목·금액·합계)을 모달로 드릴다운 조회할 수 있어야 한다.
- 인건비 계획월 금액 클릭 시 투입계획(조직·성명·MM·단가·상태) 조회를 제공해야 한다.
- 원가현황에서 예산 확정 단계로 이동할 수 있어야 한다(편집은 원가조정 소메뉴 소관).
