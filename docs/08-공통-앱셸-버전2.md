# 08. 공통 — 버전2 앱 셸 (전 화면)

> 작성: 정진 · 2026-10-07 (10-07 2차 정정) · rawdata: [`rawdata/screens/app-shell-v2.yaml`](rawdata/screens/app-shell-v2.yaml)

## 1. 목적

실행예산과 IF로 연결되는 선행 시스템 **AiPMO**(CP 금액 산정)와 **Talent AX**(인력·육성)가
AXGENTIC WIRE 브랜드로 UI를 통일해 오픈했다. 메인화면에서 먼저 시도한 버전2(01 문서 10장)를
**전 화면으로 넓혀 개발자 전달용 확정 UI**를 만든다.

- 기존 기능·버튼·배치는 **그대로** 둔다. 바꾸는 것은 바깥 틀과 공통 부품의 **모양**뿐이다.
- 버전1은 토글로 언제든 다시 볼 수 있다. 버전1 렌더 경로는 한 줄도 건드리지 않았다.
- 각 화면 파일(수진·석완 담당 포함)은 수정하지 않았다. 새 전용 파일 2개가 틀을 주입하고 모양을 덮는다.

## 2. 레퍼런스 분석

### AiPMO — 틀과 목록 화면의 원형

| 영역 | 구성 |
|---|---|
| 바탕 | 회청색 바탕 위에 **큰 흰 패널 하나**(라운드 약 16px, 사방 여백). 상단 바 없음 |
| 레일 | 바탕과 같은 회청색. 로고 → 섹션 라벨("사업기회 관리") → 흰 카드 안 **아이콘 타일 3개**(선택 시 연파랑 바탕+파랑) → 최근 조회 목록 → 하단 링크(RM 관리·게시판 ›) → 구분선 → 사용자 |

## 4. 레일 구성

```
[✳] AXGENTIC WIRE                    [◧ 접기]
    AiBudget                            (로고 클릭 = 메인 복귀)
─────────────────────────────────── (여기부터 스크롤)
▤ 담당 프로젝트 4                      ← 01 문서의 아코디언 그대로
  └ 프로젝트 ▸ 계정(인건비·외주비·경비…) ← 클릭 = 해당 계정 원가조정으로 이동
─────────────────────────────────── (아래 고정)
  화면 설명 · 그라운드 룰 · AI 네비게이터 · AI개발 Agent · 구매시스템 참고
  [상단 메뉴 보기  개발용]              ← 개발 테스트 전용
  [화면 버전  버전1 | 버전2]
  (이) 이봄 · PM · NOVA PMO팀        ›
```

- 수행원가·인사이트·프로젝트 메뉴는 **레일에 없다.** 상단 메뉴였던 기능은 AI 네비게이터 질의·응답이나 담당 프로젝트 클릭으로 들어간다.
- **자동 축소**: 화면 id 와 주소의 `pj` 가 바뀌면 "새로 들어갔다"로 보고 접는다.
  같은 프로젝트 안에서 계정만 바꾸면 접지 않는다(상세에서 직접 편 레일을 유지).
  상세에서 펴고 접은 상태는 저장하지 않고, 메인의 접기 선택만 저장한다(`newmis.v2Rail`).
- 접으면 64px — 마크·유틸 아이콘·아바타만 남고, 버전 토글은 "V2" 한 칸이 된다.
  폭은 즉시 바뀐다. 애니메이션이 멈추면(백그라운드 탭 등) 본문이 레일 밑으로 들어가는 문제가 있었다.
- 960px 이하에서는 자동으로 접힌다.
- **상단 메뉴(개발용)**: 켜면 상단 바가 레일 오른쪽에 나타나고 선택이 저장된다(`newmis.v2TopMenu`).

## 7. 예산관리 Agent (상세 화면)

- 버전2 에서 수행원가 원가조정은 **Agent ON** 으로 열린다. 예산 조정안은 Agent 질의로 나오는 시뮬레이션이고,
  기안 → 결재 상신 → 직책자 승인(확정)을 거쳐 계정별 원가에 반영되는 흐름이다.
- `budget-agent-console.js`(석완)는 수정하지 않았다. 기본값 변수만 버전에 맞춰 바꾼다.
- **흐름 동일 확인 (2차)** — 버전1(Agent 수동 ON)과 버전2에서 같은 절차를 눌러 단계별 결과가 같음을 확인

| 단계 | 버전1 | 버전2 |
|---|---|---|
| "경비 300만원 줄여줘" 보내기 | 25,000,000 → 22,000,000 | 같음 |
| 바로 기안 → 결재선 → 결재 상신 | 상신됨(submitted) | 같음 |
| 직책자 "기안 전체 승인" | 확정(confirmed) · 이력 v4.0 "Agent 제안 1건 반영" | 같음 |
| Agent 화면 버튼·입력 | 버튼 30 · 입력 1 · 동작 14종 | 같음 |

### 대화 한 줄기 (3차)

메인에서 물어 수행원가로 넘어오면 오른쪽 "AI 에이전트" 창과 가운데 "Agent와 대화하기"가 겹쳐 보였다.
버전2에서는 **가운데 하나로** 합친다. 두 에이전트를 구분하지 않고 같은 업무의 질의 흐름 하나로 본다.

```
Agent와 대화하기
  🤖 오늘 4개 소스를 점검했습니다 …          ← 원래 Agent 대화
  👤 예산관리시스템 목업용 해야 할 일 알려줘     ← 메인에서 나눈 대화
  🤖 해야 할 일 5건 [인건비 이동 →] …
  ───── 📍 예산관리시스템 목업용 · 인건비 원가조정 ─────
  🤖 고르신 "SCM에서 확정된 인력 2명…" 건은 인건비 +70,000,000원 조정안으로 …
  👤 경비 300만원 줄여줘                     ← 여기부터 Agent 가 원래대로 처리
```

- 들어올 때: 메인 대화를 시간 순서대로 이어 붙이고 오른쪽 창과 우하단 대화 버튼은 감춘다.
- 나갈 때: 가운데에서 나눈 대화가 메인 대화 뒤에 이어진다. 메인에서 다시 물어도 대화를 지우지 않는다.
- 넘기지 않는 것: 담당 배정 줄("…가 담당합니다"), 처음 여는 안내 문구, 이미 마친 "지금 이동 →" 버튼.
- "외주비 원가조정 화면으로 가줘"처럼 계정까지 말하면 그 계정 화면으로 바로 간다.
- 버전1 은 기존처럼 오른쪽 창에서 이어진다.

**넘어오자마자 대화를 잇는다 (5차)** — "이어서 여기서 말씀하세요" 같은 안내로 흐름을 끊지 않는다.

| 메인에서 한 것 | 넘어온 뒤 Agent 가 잇는 말 |
|---|---|
| "목업용 경비 300만원 줄여줘" (프로젝트 + 금액 조정) | 경비 화면으로 가서 바로 계산 — 위 금액이 바뀌고 기안 버튼이 뜬다 |
| 할 일·이상징후 항목의 "이동 →" | 고른 항목의 조정안 금액과 근거, 반영 방법 |
| "외주비 원가조정으로 가줘" | 외주비에 걸린 조정안 제목·금액 |
| 분석 질문 (답이 늦게 옴) | 메인 AI 의 답이 그대로 이어짐 |

- 계정 내역을 펼치면 예산 조정안 자리를 내역이 쓰는 배치(석완님 설계, 2026-09-04)는 그대로 둔다(사용자 결정).

**가운데 입력은 질문 유형으로 나눈다 (4차)** — 대화창이 하나가 되었으니 그 입력창에서 무엇이든 물을 수 있어야 한다.

| 질문 | 답하는 곳 | 예 |
|---|---|---|
| 예산 조정·기안 | 예산관리 Agent (지금 그대로) | 외주비 3천만원 늘려줘 · 기안해줘 · 되돌려줘 · CP 여유 얼마야? · 인건비 상세 보여줘 |
| 화면 이동 | 메인 AI → 그 화면으로 이동, 대화는 오른쪽 창에서 이어짐 | 인사이트 종합 현황 화면으로 가줘 · 메인으로 가줘 |
| 이상징후 · 할 일 | 메인 AI (지금 보는 프로젝트 기준) | 이상징후 있어? · 오늘 할 일 알려줘 |
| 데이터 분석 | 메인 AI (답만, 화면은 그대로) | 외주비 왜 늘었어? · 원가율 높은 프로젝트 알려줘 |
| 그 밖의 자유 질문 | 예산관리 Agent (예산 맥락으로 답함) | 이번 달 예산 어때? |

- 나누는 기준은 새로 만들지 않았다. Agent 쪽은 Agent 의 해석기, 메인 쪽은 메인 대화의 질문 분류기를 그대로 쓴다.
- 메인 AI 가 답하는 동안 "…" 말풍선이 보이고, 답은 같은 대화에 바로 이어진다.

## 8. 구현 메모

- **파일**: `public/js/shell-v2.js` · `public/css/shell-v2.css` (신규). `index.html` 에는 로드 줄 2줄만 추가했다.
  `shell-v2.js` 는 **맨 마지막**에 로드되어 `dashboard.js` 의 같은 이름 정의(`renderHomeV2` · `setHomeVer` · `v2ApplyRail` · `toggleV2Rail`)를 덮는다.
- **기본값 버전2**: `homeVer` 는 `dashboard.js` 의 최상위 `let` 이라 다른 스크립트에서도 같은 바인딩이다.
  `localStorage` 에 선택이 없을 때만 `'v2'` 로 바꾼다.
- **메인화면**: 레일이 앱 셸로 나갔으므로 `renderHomeV2()` 는 히어로만 그린다. 흰 패널 자체가 카드라 히어로의 안쪽 카드는 걷었다.
- **이중 여백 제거**: `#s-budget`(좌96/우44px), `#s-insights`(26px)는 버전1의 전체 폭 기준 여백이 있어 버전2에서만 걷었다.
- **잘림 방지**: 표 카드를 `overflow:hidden` 으로 두면 좁은 폭에서 삭제 버튼이 잘려 `overflow-x:auto` 로 바꿨다.
- **캐시**: 새 파일은 새 `?v=` 로 로드되어 첫 접속부터 최신이 적용된다.

## 9. 버전 비교·되돌리기

- 레일 하단 **화면 버전 [버전1 | 버전2]** — 버전1 을 누르면 모든 화면이 원형으로 돌아간다.
- 버전1 상태에서는 메인 외 화면 **좌하단**에 같은 전환 버튼이 뜬다(메인은 기존 우측 상단 탭).
- 선택은 브라우저에 저장된다(`newmis.homeVer`).
