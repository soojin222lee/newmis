# 10. 관리자 > AS-IS 관리자 메뉴 10종 (2026.11.27)

> 원천 데이터: `rawdata/screens/admin-member.yaml` · `admin-sgna.yaml` · `admin-acct.yaml` · `admin-client.yaml` · `admin-partner.yaml` ·

> 화면 코드: `public/js/admin-asis.js` (작성: 남주) · AS-IS 원본: `base-front/src/views/admin` · `shared`

## 왜 필요한가

AS-IS 관리자 시스템(base-front)에는 있는데 목업 어드민에는 없던 화면을 옮겼습니다.
목업 어드민은 사용자 · 권한 · 코드 같은 핵심 메뉴만 있었고, 고객사 · 협력사 · 계정과목 같은 **기준정보 조회**와
게시판 · 첨부파일 · IP접근제어 같은 **운영 메뉴**가 빠져 있었습니다.

## 무엇을 옮겼나

AS-IS 관리자 화면을 목업 메뉴와 맞춰 보고, 목업에 없는 것만 새 메뉴로 넣었습니다.

| 메뉴 그룹 | 새 메뉴 | AS-IS 원본 | 성격 |
|---|---|---|---|
| 기준정보 (마스터) | 구성원 조회 | `admin/member/MemberManagement.vue` | 조회 전용 (HR) |
| | SG&A 조직 관리 | `admin/organization/SgnaOrganizationManagement.vue` | 트리 등록 · 수정 · 삭제 |
| | 계정과목 조회 | `admin/accountTitle/AccountTitleManagement.vue` | 조회 전용 (ERP) |
| | 고객사 조회 | `admin/client/ClientManagement.vue` | 조회 전용 + 상세 (ERP) |
| | 협력사 조회 | `admin/partner/PartnerManagement.vue` | 조회 전용 + 상세 (구매) |
| 권한 · 접근 | 사용자 그룹 관리 | `shared/userGroup/UserGroupManagement.vue` | 그룹 + 멤버 관리 |
| | 화면 관리 | `admin/page/PageManagement.vue` | 등록 · 수정 · 삭제 |
| | IP접근제어 관리 | `admin/ipAccessControl/IPAccessControlManagement.vue` | 등록 · 엑셀 업로드 · 운영모드 전환 |
| 운영 · 연계 | 게시판 관리 | `admin/board/` (공지사항 · Q&A · 매뉴얼) | 탭 3개 |
| | 첨부파일 관리 | `admin/attachedFile/AttachedFileManagement.vue` | 폴더 + 파일 |

**옮기지 않은 것 (요청으로 제외):** 휴무일 관리 · 배치 관리 · 위젯 관리 · 탭 관리 · 워크플로우 관리.
목업에 원래 있던 **배치/스케줄** 메뉴는 그대로 둡니다.

**목업에 이미 있어 새로 넣지 않은 것:** 사용자 관리 · 권한 관리(+ 사용자 역할 관리) · 메뉴 관리 · 조직도 · 표준노무비(=P단가) ·
환율 · 분류체계(=코드 관리) · 회계결산일자 · 결재선(=결재라인) · 메일발송(=메일관리). 이 메뉴들은 다음 단계에서 AS-IS와 칸 단위로 비교합니다.

## 메뉴 11개로 묶기 (탭으로 구분)

메뉴가 25개(기존 15 + 새 10)가 되어 찾기 어려워졌습니다. **11개로 줄이고, 묶인 메뉴는 화면 위쪽 탭으로 나눕니다.**
원래 화면과 기능은 그대로입니다. 탭 아래에는 그 탭의 설명과 데이터 출처가 한 줄로 나옵니다.

| 레일 묶음 | 메뉴 | 탭 |
|---|---|---|
| 기준정보 (마스터) | 사용자 관리 | 사용자 · 구성원 조회 · 사용자 그룹 |
| | 조직 관리 | 조직도 · SG&A 조직 |
| | 기준정보 관리 | 공통코드 · 계정과목 · P단가 · 환율 · 회계결산일자 |
| | 거래처 관리 | 고객사 · 협력사 |
| | 결재라인 관리 | (탭 없음) |
| 권한 · 접근 | 권한 · 보안 관리 | 역할별 권한 · IP접근제어 · 로그 · 이력 |
| | 메뉴 · 화면 관리 | 메뉴 · 화면 |
| 운영 · 연계 | 알림 · 메일 관리 | 운영 알림 · 메일 발송 이력 |
| | 시스템 운영 | 외부 연동 · 배치 / 스케줄 |
| | 게시판 · 자료 관리 | 공지사항 · Q&A · 매뉴얼 · 첨부파일 |
| Agent 평가 | Golden Data set 관리 | (탭 없음) |

- **로그 · 이력은 권한 · 보안 관리에 둡니다.** 로그 · 이력은 누가 무엇을 했는지 보는 조회 전용 감사 기록이고,
  배치 / 스케줄은 작업을 돌리는 도구(자체 실행 이력도 있음)라 한 메뉴에 두면 헷갈립니다.
  메일 발송 이력은 재발송까지 하는 메일 운영 화면이고 AS-IS도 메일링리스트 · 템플릿과 한 묶음이라 알림 · 메일 관리에 둡니다.
- 메뉴를 다시 고르면 그 묶음에서 마지막으로 보던 탭이 열립니다.
- 예전 주소(`#fx` · `#closedate` · `#ip` …)로 들어와도 해당 묶음의 해당 탭이 열립니다.
- 코드: `public/js/admin-menu-group.js` — 다른 관리자 파일은 고치지 않고 맨 뒤에서 메뉴 목록을 바꿔 끼웁니다.
  원천 데이터: `rawdata/screens/admin-menu-group.yaml`

## 조직도는 조회 전용으로

AS-IS 조직도(`OrganizationManagement.vue`)에는 등록 · 수정 · 삭제가 없습니다(HR에서 받음). 목업도 맞췄습니다.

- 뺀 것: [＋ 부서 등록] · 행별 수정 · 삭제 · 저장, 조직장 · 인원 표시
- 넣은 것: AS-IS 칸(조직명 · 조직영문명 · 조직별칭)과 검색(조직명 · 조직영문명 · 조직별칭 중 골라 조회)
- 원천 데이터: `rawdata/screens/admin-org.yaml`

## 화면별 핵심

- **구성원 조회**: 왼쪽 조직(본부 → 팀)을 누르면 그 조직 사람만 봅니다. 본부를 누르면 아래 팀까지 함께 봅니다.
- **SG&A 조직 관리**: 판관비 집계용 조직 트리입니다. 조직을 골라 하위 조직을 등록하고, 접고 펼 수 있습니다.
  하위가 있는 조직을 지우면 하위 개수를 알리고 함께 지웁니다. 종료 일자가 지난 조직은 회색입니다.
- **계정과목 · 고객사 · 협력사 조회**: AS-IS처럼 "어느 칸으로 찾을지" 라디오를 고르고 검색어를 넣어 조회합니다.
  고객사 · 협력사는 줄을 누르면 오른쪽에 상세(13개 · 15개 항목)가 열립니다.
- **사용자 그룹 관리**: 왼쪽에서 그룹을 고르면 오른쪽에 멤버가 보입니다. [＋ 사용자 추가]는 구성원 목록에서 여러 명을 체크해 넣습니다.
- **화면 관리**: 메뉴 관리가 연결하는 화면(라우팅 · 서비스 경로)을 등록합니다. 서비스모드 ON 화면은 운영모드 중에도 열립니다.
- **IP접근제어 관리**: 운영모드(긴급) 때 접속을 허용할 IP입니다. IP 형식이 틀리면 저장되지 않습니다.
  [운영모드 전환]은 AS-IS처럼 **두 번 확인**합니다(접속 중인 모든 사용자 로그아웃 안내).
- **게시판 관리**: 공지사항(구분 · 메인팝업) · Q&A(상태 칸을 눌러 답변 등록) · 매뉴얼(메인 매뉴얼 한 건 지정) 탭입니다.
- **첨부파일 관리**: 왼쪽 폴더를 고르면 그 폴더(하위 포함) 파일만 봅니다. 상세 조회 · 다운로드 · 업로드 · 폴더 등록이 됩니다.

## AS-IS와 다르게 한 것

| AS-IS | 목업 | 이유 |
|---|---|---|
| 그리드에서 [행추가] → 칸에 바로 입력 → [행삭제] 체크 → [저장] | [＋ ○○ 등록] 팝업 · 행별 [수정] · [삭제] 확인 팝업 · [저장] | 목업 어드민 다른 메뉴와 같은 방식으로 맞춤 |
| 페이지 이동(페이징) | 없음 | 목업 데이터가 적음 |
| 엑셀 업로드 · 다운로드 · 운영모드 전환이 실제 동작 | 안내 팝업 · 토스트만 (목업 스텁) | 서버 없음 |
| 고객 · 협력사 · 사용자 검색 팝업 테스트 버튼 | 없음 | AS-IS 개발용 테스트 버튼 |

## 구현 메모

- `admin.js`(수진)는 고치지 않았습니다. `admin-asis.js`가 뒤에 로드되어 `ADMIN_SECTIONS`에 메뉴를 더하고
  `admSectionBody`를 감싸 자기 메뉴만 그립니다(결재라인 · 회계결산일자와 같은 방식).
- 저장은 브라우저 `localStorage`(`budgetai.admin.asis.v1`)입니다. 목업 데이터는 가상의 회사 · 사람입니다.
- 조회 조건은 입력만 해서는 적용되지 않고 **[조회]**(또는 Enter)를 눌러야 적용됩니다(AS-IS와 같음).
